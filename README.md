# Raditya.Dev

Portfolio personal modern untuk **Raditya.Dev**, dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan Website

Buka file `index.html` langsung di browser, atau jalankan local server:

```powershell
python -m http.server 8080
```

Kemudian kunjungi `http://localhost:8080`.

## Struktur

- `index.html` — struktur dan konten website
- `style.css` — desain, warna, animasi, dan layout responsif
- `script.js` — interaksi navigasi

## Kustomisasi

- Nama, profil, dan alamat email dapat diubah pada `index.html`
- Warna utama berada pada variabel CSS `--accent` dan `--bg`
- Konten skill dan proyek dapat diperbarui pada bagian `skills` dan `projects`
- Tautan GitHub dan Instagram di bagian Contact masih berupa alamat contoh dan perlu diganti
